# Windows Manage Init Pattern

## Description

This pattern runs one-time system initialization on Windows through Ansible Automation Platform.

## Surveys

- **System Initialization Survey**: Prompts users for init message and final actions (reboot, syslog).

## How to Use

1. Execute the "Seed Red Hat pattern" job and select the "Windows" category.
2. Run `Windows Operations / System Init` job template.
