# Windows Manage Time Pattern

## Description

This pattern automates Windows NTP and timezone configuration through Ansible Automation Platform.

## Surveys

- **Manage Time Survey**: Prompts users to specify timezone and reboot preference.

## How to Use

1. Execute the "Seed Red Hat pattern" job and select the "Windows" category.
2. Run `Windows Operations / Manage Time` job template.
