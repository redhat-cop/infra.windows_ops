# Windows Manage Recovery Pattern

## Description

This pattern manages Windows Recovery Environment (WinRE) through Ansible Automation Platform.

## Surveys

- **Manage Recovery Environment Survey**: Prompts users to enable or disable WinRE.

## How to Use

1. Execute the "Seed Red Hat pattern" job and select the "Windows" category.
2. Run `Windows Operations / Manage Recovery` job template.
