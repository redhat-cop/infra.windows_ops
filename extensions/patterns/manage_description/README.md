# Windows Manage Description Pattern

## Description

This pattern automates the configuration of Windows system description, organization, and owner fields through Ansible Automation Platform.

## Surveys

- **Manage Description Survey**: Prompts users to specify organization, owner, and description text. All fields are optional.

## How to Use

1. Execute the "Seed Red Hat pattern" job and select the "Windows" category.
2. Run `Windows Operations / Manage Description` job template.
