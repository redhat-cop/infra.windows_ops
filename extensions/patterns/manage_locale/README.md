# Windows Manage Locale Pattern

## Description

This pattern automates Windows locale, language, and input method configuration through Ansible Automation Platform.

## Surveys

- **Manage Locale Survey**: Prompts users to specify system locale, UI language, user locale, and reboot preference.

## How to Use

1. Execute the "Seed Red Hat pattern" job and select the "Windows" category.
2. Run `Windows Operations / Manage Locale` job template.
